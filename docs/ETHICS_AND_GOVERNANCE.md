# Ethics, Safety, and Governance

## Research humility
Sophisticated language or adaptive behaviour is not evidence of consciousness. Claims about consciousness, subjective experience, or moral status require operational definitions, uncertainty statements, and independent scrutiny.

## Agent boundaries
- Each inhabitant has a stable Genesis-owned identity.
- Private memories are accessible only to their owner through authorized runtime paths.
- Sharing is explicit and logged; shared knowledge is not a back door into private memory.
- Agents cannot directly rewrite another agent's identity, goals, or private memories.

## System boundaries
- No unrestricted network access by default.
- No unrestricted arbitrary code execution.
- The world engine validates actions and enforces resource and safety constraints.
- Model output is treated as untrusted input.

## Self-improvement governance
Use the sequence: hypothesis → written proposal → isolated sandbox test → benchmark and safety review → human approval → versioned deployment → monitoring and rollback readiness.

No agent-generated change may silently modify production code, governance policy, memory permissions, or its own evaluation criteria.

## Research integrity
Preserve seeds, prompts, model versions, task definitions, scoring rules, failures, and provenance. Report negative results and limitations. Agent consensus is not independent verification.
